# Bilingual Terminology Glossary (Hindi <-> English)

**Citizen Scheme Assistant (नागरिक योजना सहायक)**  
Document Version: 1.0.0

To ensure consistency across the UI, decision explanations, voice prompts, and document checklists, this glossary establishes standard translations between English and Hindi.

> **Guideline**: We prefer simple, conversational Hindi (बोलचाल की हिंदी) over dense Sanskritized bureaucratic terminology. When official terms cannot be avoided, provide the conversational equivalent alongside.

---

## 1. Core Evaluation & System Terms

| English Term | Standard Hindi (हिंदी) | Conversational / Clarifying Note |
| :--- | :--- | :--- |
| **Eligibility / Eligible** | पात्रता / पात्र | आप इस योजना के पात्र हैं (You qualify) |
| **Not Eligible / Ineligible** | अपात्र | वर्तमान में अपात्र (Currently do not qualify) |
| **Uncertain / Need More Info** | संशय / अधिक जानकारी आवश्यक | निश्चित रूप से कहने के लिए और जानकारी चाहिए |
| **Government Scheme** | सरकारी योजना | सरकारी योजना |
| **Criteria / Condition** | नियम / शर्त | योजना की मुख्य शर्तें |
| **Reason / Decisive Rule** | कारण / निर्णायक नियम | यह निर्णय किस नियम के आधार पर लिया गया |
| **Required Documents** | आवश्यक दस्तावेज़ | ले जाने वाले ज़रूरी कागज़ात |
| **Official Source** | आधिकारिक स्रोत | सरकारी वेबसाइट का सीधा लिंक |
| **Last Checked Date** | नियम सत्यापन तिथि | यह नियम कब जांचा गया |
| **Clear Session / Wipe Data** | डेटा मिटाएं / नया नागरिक | इस फ़ोन से सारी जानकारी तुरंत हटाएं |
| **Voice Input (Speak)** | बोलकर उत्तर दें | माइक दबाकर बोलें |
| **Read Aloud (Listen)** | पढ़कर सुनाएं | आवाज़ में सुनें |

## 2. Demographic & Socio-Economic Terms

| English Term | Standard Hindi (हिंदी) | Conversational / Clarifying Note |
| :--- | :--- | :--- |
| **Annual Household Income** | परिवार की कुल वार्षिक आय | साल भर में पूरे परिवार की कुल कमाई |
| **Below Poverty Line (BPL)** | गरीबी रेखा से नीचे (बीपीएल) | बीपीएल राशन कार्ड धारक |
| **Antyodaya (AAY)** | अंत्योदय अन्न योजना | गुलाबी / पीला अंत्योदय कार्ड |
| **Land Ownership / Holding** | कृषि भूमि स्वामित्व | आपके नाम पर खेती की ज़मीन |
| **Small & Marginal Farmer** | लघु एवं सीमांत किसान | 2 हेक्टेयर (लगभग 5 एकड़) से कम ज़मीन वाले |
| **Pucca House** | पक्का मकान | ईंट, सीमेंट या कंक्रीट की पक्की छत वाला घर |
| **Kutcha House** | कच्चा मकान | मिट्टी, बांस, घास-फूस या टीन की छत वाला मकान |
| **Street Vendor / Hawker** | रेहड़ी-पटरी / ठेला विक्रेता | सड़क किनारे दुकान या ठेला लगाने वाले |
| **Daily Wage Worker** | दिहाड़ी मज़दूर | रोज़ाना मजदूरी करने वाले |
| **Income Tax Payee** | आयकर दाता | जो सरकार को इनकम टैक्स भरते हैं |

## 3. Official Document Types

| English Term | Standard Hindi (हिंदी) | Issuing Authority / Where to get |
| :--- | :--- | :--- |
| **Aadhaar Card** | आधार कार्ड | UIDAI |
| **Bank Passbook** | बैंक पासबुक | Bank / Post Office (खाते की पासबुक) |
| **Ration Card** | राशन कार्ड | खाद्य एवं रसद विभाग (Food & Civil Supplies) |
| **Income Certificate** | आय प्रमाण पत्र | तहसील / राजस्व विभाग (Tehsildar / Revenue) |
| **Caste Certificate** | जाति प्रमाण पत्र | तहसील / अनुमंडल अधिकारी (SDM Office) |
| **Land Ownership Record (Khatauni/Khasra)** | भू-अभिलेख (खतौनी / खसरा) | राजस्व विभाग / भूलेख पोर्टल |
| **Vending Certificate / Urban Livelihood ID** | वेंडिंग प्रमाण पत्र / परिचय पत्र | नगर निगम / नगर पालिका (Municipal Body) |
| **Age Proof / Birth Certificate** | आयु प्रमाण / जन्म प्रमाण पत्र | पंचायत / नगर निगम / स्कूल प्रमाण पत्र |
| **Disability Certificate** | दिव्यांगता प्रमाण पत्र | जिला चिकित्सालय (Chief Medical Officer) |

## 4. Administrative Authorities & Walk-in Points

| English Term | Standard Hindi (हिंदी) | Practical Citizen Guidance |
| :--- | :--- | :--- |
| **Common Service Centre (CSC)** | जन सेवा केंद्र / प्रज्ञा केंद्र | गाँव या कस्बे की अधिकृत ऑनलाइन सेवा दुकान |
| **Gram Panchayat** | ग्राम पंचायत | ग्राम प्रधान या पंचायत सचिव का कार्यालय |
| **Tehsil / Sub-Divisional Office** | तहसील / एसडीएम कार्यालय | ब्लॉक या तहसील मुख्यालय |
| **Post Office Bank** | डाकघर बचत बैंक (IPPB) | निकटतम शाखा या डाकिया के माध्यम से |
